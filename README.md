# Prototipo -- Colaboradores

Pantalla de Colaboradores del portal de Veeda: alta de una persona a la vez,
carga masiva por Excel con validaciones dentro del archivo, invitacion por
WhatsApp y baja.

Es un prototipo: los datos son generados y viven solo en el navegador. No hay
backend y nada se guarda al recargar.

Se ve en https://veedahq.github.io/veeda-colaboradores-demo/
